📖 MY Military Navigation — Simple User Guide

Quick "where to click" instructions.

App: https://military-navigation.jimmy.je

Bottom bar = 5 screens: COMPASS · MAP · POINTS · CONVERT · SETTINGS

📲 How to install (Add to Home Screen)

Install it once and it opens like a normal app — no browser bar, works offline once loaded.

iPhone / iPad (Safari):

  1. Open the app in Safari (must be Safari, not Chrome).
  2. Tap the Share button (square with an up-arrow).
  3. Scroll down → tap Add to Home Screen.
  4. Tap Add (top-right).
  5. Launch it from the new icon on your home screen.

Android (Chrome):

  1. Open the app in Chrome.
  2. Tap the ⋮ menu (top-right).
  3. Tap Add to Home screen / Install app.
  4. Confirm → launch from the new icon.
💡 iPhone tip: after installing, open it from the home-screen icon (not Safari) and allow Location + Motion & Orientation when prompted — GPS and compass need it.

💾 How to save your current location (Compass view)

  1. Tap COMPASS (bottom bar).
  2. Wait for the GPS dot (top-left) to turn green.
  3. Tap the green SAVE button under the compass.
  4. Type a NAME, pick a COLOR, tap SAVE.

💾 How to save a location from the Map

  1. Tap MAP (bottom bar).
  2. Drag/zoom the map until the crosshair (screen center) sits on the spot.
  3. Tap SAVE in the coordinates bar at the bottom.
  4. Type a NAME, pick a COLOR, tap SAVE.
💡 This saves the point under the crosshair — you don't need to be standing there.

📋 How to view / edit / delete a saved location

  1. Tap POINTS (bottom bar).
  2. All saved locations are listed here.
  3. Tap a location → options to edit, copy coordinates, or set as target.
  4. Delete several at once: tap SELECT (top) → tick the boxes → DELETE → confirm.

📏 How to check distance & bearing between two coordinates

  1. Tap MAP → tap the navigate icon (right side, arrow/route button).
  2. In ORIGIN: type a saved location name or paste any coordinates.
  3. In DEST: same.
  4. Tap CONNECT.
  5. Read the result on the map: DST (distance) and HDG (bearing in MILS).

⛰️ How to check elevation profile between two coordinates

  1. Follow the steps above (ORIGIN + DEST → CONNECT).
  2. Tap PROFILE.
  3. The terrain height chart appears.
  4. Tap DOWNLOAD to save it as a PNG image.

🚶 How to start / stop navigation (walk the bearing)

Start:

  1. Tap MAP → navigate icon.
  2. Set ORIGIN and DEST → tap CONNECT.
  3. Tap GO — the map switches to Track-Up and locks onto your GPS.
  4. Hold your phone flat, follow the heading line. Watch DST count down and BRG update live.

Stop:

  • Tap the red STOP NAV button on the map.

🔍 How to search a coordinate

  1. Tap MAP → tap the magnifier icon (right side).
  2. Type or paste coordinates — any format works (MGRS, Lat/Lng, RSO grids).
  3. Tap GO — the map jumps to that point.

⚙️ How to change the coordinate format

  1. Tap SETTINGS (bottom bar).
  2. Under POSITION FORMAT, pick one:
    • MGRS — military grid (NATO standard)
    • Lat/Lng (DD) or (DMS)
    • EPSG:3375 — GDM2000 Peninsular Malaysia
    • EPSG:3376 — GDM2000 Sabah & Sarawak
    • EPSG:3168 — Kertau 1968 (legacy)
    • EPSG:29873 — Timbalai 1948 (legacy Borneo)
    • EPSG:3377–3385 — GDM2000 State Cassini Grids (Johor, Sembilan & Melaka, Pahang, Selangor, Terengganu, Pinang, Kedah & Perlis, Perak, Kelantan)
  3. Done — the whole app switches instantly.

🔄 How to convert coordinates (Convert view)

  1. Tap CONVERT (bottom bar).
  2. Set FROM = the format you're pasting in.
  3. Set TO = the format you want out.
  4. Type or paste your coordinates in the INPUT box — one coordinate per line.
  5. The OUTPUT box updates live as you type:
    • ✓ = converted successfully
    • ✗ (unparsed) = that line couldn't be read (check its format)
  6. Tap COPY to copy all results, or CLEAR to start over.
💡 You can mix lines — one bad line just shows ✗, the rest still convert.

Example — 2 points from DD to a State grid:

2.0, 103.5
1.5, 103.8

→ set FROM = Lat/Lng (DD), TO = EPSG:3377 → get -6793 E -4696 N and 26593 E -59981 N.

⚠️ Typing an EPSG grid as input? Use the E…N form, e.g. -6793 E -4696 N (not -6793, -4696).

🧭 How to switch MILS ↔ DEGREES

  • Quick way: COMPASS view → tap the FORMAT button.
  • Settings way: SETTINGS → COMPASS UNITS → MILS (6400) or DEGREES (360).

🗺️ How to change the map layer

  • Quick way: MAP view → tap the layers icon (right side) to cycle: Satellite → Topographic → Hybrid.
  • Settings way: SETTINGS → MAP TYPE → pick your default.

🧲 How to fix the compass / GPS if it's not working

  1. Tap SETTINGS → scroll to SENSOR PERMISSIONS.
  2. Tap REQUEST LOCATION → allow.
  3. Tap REQUEST ORIENTATION → allow. (iPhone users: this is required!)
  4. Still stuck? Make sure you're on the https:// link, and step outdoors for GPS.

📤 How to export / back up your locations

  1. Tap POINTS.
  2. All locations: tap EXPORT (top) → choose JSON (backup) or GPX (for Garmin/Gaia/QGIS).
  3. Only some: tap SELECT → tick the boxes → EXPORT.
💡 Export a JSON backup regularly — your saved locations live only in this browser.
