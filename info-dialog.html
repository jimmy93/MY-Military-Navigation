Overview

Military Navigation (v1.0) is a tactical web application designed for field operators in the Malaysia. It provides real-time compass orientation, satellite mapping, waypoint management, and coordinate conversion across multiple local and international grid systems.

This app is 100% Free. All data is stored locally on your device — nothing is uploaded to any server.

Coordinate Formats

Seven formats are supported (switchable in Settings):

  • MGRS — Military Grid Reference System
  • Lat/Lng (DD) — Decimal Degrees
  • Lat/Lng (DMS) — Degrees Minutes Seconds
  • GDM2000 Peninsular RSO — EPSG:3375 (West Malaysia)
  • GDM2000 East Malaysia RSO — EPSG:3376 (Sabah, Sarawak)
  • Kertau 1968 Malaya RSO — EPSG:3168
  • Timbalai 1948 Borneo RSO — EPSG:29873
Screens
  • Compass — MILS/DEG heading, SAVE/Copy, drag to test
  • Map — Satellite/topo/hybrid, crosshair SAVE/COPY, Track-Up mode
  • Navigation — Origin/Dest inputs, CONNECT/GO/CLEAR with arrow vector
  • Points — Waypoint list, edit/copy/target, SELECT mode for bulk export
Tips
HTTPS required for sensors. iOS users tap Settings → Request.
RSO projections use EPSG-precise proj4 parameters (sub-cm accuracy).
Privacy & Export

All data stays in your browser. Export as JSON or GPX.
